# Day 1 - What Does an AI System Actually Do?

## Simple AI Pipeline

Input → AI Model → Output

Example:
- Question → AI understands → Answer
- Image → AI analyzes → Result

---

## 3 Real-World AI Products

### 1. ChatGPT
- Input: User question
- Processing: AI understands the question.
- Output: Answer in text.

### 2. Google Translate
- Input: English text.
- Processing: AI translates the language.
- Output: Hindi text.

### 3. Spotify Recommendations
- Input: User's listening history.
- Processing: AI finds music preferences.
- Output: Recommended songs.

---

## How a Chatbot Works

A chatbot is a computer program that can talk with people.
It receives the user's message as input.
The AI understands the meaning of the message.
Then it processes the request and generates a suitable response.
Finally, it sends the answer back to the user.
